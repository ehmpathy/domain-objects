## C-1: the timestamp hook refused the goals ledger

**class: repo quirk.** the hook did its job. the defect lives in a writer that only this kind of repo has: a route driven by a bhrain achiever, whose verbatim ask ledger sits in a tracked dir.

why not a practice bug:
- declapract-typescript-ehmpathy states the hook blocks every timestamp in every tracked file, with zero exemptions, and names privacy as the reason: `.agent/repo=.this/role=any/briefs/rule.forbid.timestamp-hook-exemptions.md:5-7,11-12`
- its answer for this exact case: *"exempt `<dir>/`, its writer appends a clock" → fix the writer; catch a reseed dream if it lives in another repo* (same file, line 32)
- the only skip is `*.ts | *.sh`, and a test fails if it grows (lines 15, 22-23). so an exemption for `.goals/` would be a blocker there, and is not asked for

why not an adoption candidate: the local fix (unstage, commit with `--unstaged ignore`) is a per-commit move, not a pattern worth spread. the durable fix is upstream.

the ledger also leaks the wisher's orders verbatim, so the hook caught a privacy leak beyond the clock time. that is the hook's stated purpose, as designed.

feedback: `dreams/v2026_11_21.reseed-achiever-goals-ledger-tracked.md`. the achiever should ship a `.gitignore` for `$route/.goals/`, as the driver does for `.route/`.

## C-2: the template's commit header

**class: practice bug, in the route template.** the defect is general, not special to this repo: any upgrade route on a branch whose name says `feat` hits it.

- cite: `rhachet-roles-ehmpathy` `src/domain.roles/mechanic/skills/declapract.upgrade/templates/3.3.repair.cicd.defects.stone:16` hardcodes `printf 'fix(practs): bump to latest best…'` (also cut short: no `practices`)
- `git.commit.set` infers the level from the branch name and refuses a mismatch; its refusal names the fix, so the cost was one round trip
- not in declapract-typescript-ehmpathy: the command sits in the route's stone text, which the mechanic's `declapract.upgrade init` copies from its own templates (confirmed by a read of the upstream file, identical to this route's stone)

feedback: `dreams/v2026_11_21.reseed-declapract-upgrade-commit-prefix-hardcoded.md`. the template should name the level as a choice, or the init skill should bind the branch to `fix`.
