## notes / decisions

- **no `z` value import**: `getContractRef` derives sub-schemas via the author's schema *instance*
  methods (`.pick`, `.extend`, `.or`, `.meta`). this mirrors `getContract` (which never imports `z`)
  and keeps zod a type-only/author-supplied concern — `test:lint:deps` stays green.
- **`.contract.ref` hookup**: `.contract` returns `DomainObjectContract` (= zod schema + `.ref(by)`
  method). the `.ref` method is a function property; the q5b probe proved it does NOT leak into
  `z.toJSONSchema()` output, and an embedded `X.contract` still round-trips. verified again by test.
- **nested-unique recursion (q2)**: for `by:'unique'`, a unique key that names a nested dobj is
  replaced (via `.extend`) with that dobj's own `.contract.ref('unique')` sub-shape — so the wire
  schema mirrors `refByUnique`'s runtime reduction. snapshot confirms `turtle → { seawaterSecurityNumber }`.
- **`by:'ref'` (q3)**: `arms[0].or(arms[1])` (a union) with ONE top-level `by:'ref'` stamp, arms
  unstamped; union-of-one (only one grain declared) degrades to that grain's object, still `by:'ref'`.
- **files touched**: new `getContractRef.ts` + `.test.ts` + snapshot; edited `DomainObjectPragma.ts`
  (added `DomainObjectPragmaRef`/`DomainObjectRefBy`, updated base doc), `getContract.ts` (attach
  `.ref` + `DomainObjectContract` type), `DomainObject.ts` (getter return type), `index.ts` (exports).
- **getContractRef not value-exported** from index — mirrors `getContract` (also unexported); the
  public surface is `.contract` / `.contract.ref`. the *types* are exported (q4).
