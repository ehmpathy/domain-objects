> and its observed output. zero deferrals, zero fakes, zero skips in scope.

deliverable: `X.contract.ref('primary' | 'unique' | 'ref')` — a zod schema of only the referenced
key fields, stamped with an `x-domain-object-ref` pragma that survives `z.toJSONSchema()`.

"contract outputs" are the SDK return values + their json-schema pragma forms, verified by

consumer roundtrip the wish exists for. an author composes a contract that references dobjs by key
(+ one whole-dobj compose), publishes it via `z.toJSONSchema()` (the wire), and a consumer stand-in
(the sdk-aws-lambda codegen walk) reads each `x-domain-object-ref` back, binds the named class from a
registry, reconstructs each reference from a live instance via `refByPrimary`/`refByUnique`, and
validates both the reconstructed refs and a full composed payload against the published schema. four
journeys: the vision's SurfTrophy multi-ref, an **ARRAY of refs** (pragma rides on `items`; a roster of
riders reconstructed + validated at scale), nested-unique recursion across the wire, and the `by:'ref'`
union. every wire artifact + pragma map + reconstructed ref + validated payload is snapshotted.
